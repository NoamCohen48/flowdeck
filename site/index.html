A test says what must be true. A flow says what a person does.

Flowdeck runs your team's testing day: long flows on real devices, every test accounted for, results live on one board.

Install Source on GitHub

The whole team on one board

Each tester claims a flow and walks it to the end. Claims, verdicts and progress reach every screen as they happen, without a refresh.

Every step names one device

A device keeps one colour across the template, on the board, in the editor and in the runner. When a flow moves to another phone, the tester is told before the step that needs it.

  • APixel 8
  • BiPhone 13
  • CSecond laptop
One device per step
Anything that touches two screens is two steps. "Both phones" is never an instruction.
One thing per step
No "and", no "then". When a step fails, the report points at one action.
A check says what to see
Every check carries its expected result, written where the tester reads it.
Tests are statements
"Sign-in rejects a wrong password", verified by whichever flows reach it.

Results you can act on the next morning

Worst result wins
A test checked in three flows shows its worst verdict, so one failure is never averaged away.
Failures carry their context
The note, the photos, the step and the device, exported as a JSON feed your own script turns into tickets.
A wrong step is a finding too
Testers flag steps that no longer match the product, and the report says which flow to fix.
Nothing silently uncovered
A test that no flow reaches is flagged in the library, before the testing day, not after.

Write the suite as files, or let an agent write it

Pull a product into YAML, edit it in any editor, and push it back as one reviewed change. Lint runs offline with the same rules as the server. Every command speaks --json.

A pull leaves an AGENTS.md beside the files, and flowdeck guide teaches the rules to whoever is writing.

Runs on your machine, on your network

Everything Flowdeck needs comes bundled together. Unpack it on a server, start it, and your team is testing. It never reaches outside your network, so it runs just as well on a closed one.

  • Backups are encrypted and stay inside your network.
  • No internet on the server? Download the offline bundle: one file with everything inside, the CLI included.
  • No accounts to set up. People pick their name, and every change is attributed.

  1. Download the latest release.

    curl -fsSL https://github.com/NoamCohen48/flowdeck/releases/latest/download/flowdeck.tar.gz | tar -xz

  2. Start it. The first run sets everything up.

    cd flowdeck && ./start.sh

  3. Open the address it prints, and pick your name.
